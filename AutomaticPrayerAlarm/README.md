# স্বয়ংক্রিয় নামাজের এলার্ম (Automatic Prayer Alarm)

স্বতন্ত্র নামাজের রিমাইন্ডার অ্যাপ (Kotlin + Jetpack Compose)। কোনো হার্ডওয়্যার/অ্যামপ্লিফায়ার কন্ট্রোল নেই।

## APK বানানোর দুটি উপায়

### ১) Android Studio (সবচেয়ে সহজ)
1. Android Studio (Koala বা নতুন) ইনস্টল করুন।
2. **File → Open** দিয়ে এই ফোল্ডারটি খুলুন, Gradle sync শেষ হতে দিন (ইন্টারনেট লাগবে)।
3. **Build → Build APK(s)** → `app/build/outputs/apk/debug/app-debug.apk`
4. APK ফোনে নিয়ে ইনস্টল করুন (Unknown sources অনুমতি দিতে হতে পারে)।

### ২) কম্পিউটার ছাড়া: GitHub Actions
1. এই পুরো ফোল্ডার একটি GitHub রিপোজিটরিতে আপলোড করুন।
2. **Actions → Build APK → Run workflow**।
3. শেষ হলে **Artifacts** থেকে `AutomaticPrayerAlarm-debug-apk` ডাউনলোড করুন।

## মক্কার আজান (MP3) যোগ করা
আজানের শব্দ বাছাইয়ের ক্রম:
1. ওয়াক্তের সেটিং-এ বেছে নেওয়া **কাস্টম MP3**
2. সেটিংসে **"মক্কার আজান (সব ওয়াক্তের জন্য)"** থেকে বেছে নেওয়া MP3
3. অ্যাপের ভেতরে রাখা ফাইল: `app/src/main/res/raw/adhan_fajr.mp3`, `adhan_dhuhr.mp3`, `adhan_asr.mp3`, `adhan_maghrib.mp3`, `adhan_isha.mp3`; না থাকলে `adhan_makkah.mp3`; তা-ও না থাকলে `adhan_default.mp3`
   (ফাইলের নাম ছোট হাতের ইংরেজি অক্ষর, সংখ্যা ও `_` হতে হবে। `res/raw` ফোল্ডার না থাকলে বানিয়ে নিন)
4. ফোনের বাংলা TTS (যদি ভয়েস ডেটা ইনস্টল থাকে)
5. ফোনের ডিফল্ট অ্যালার্ম টোন

**মক্কার আজান পুরো অ্যাপে বসাতে:** একটি বৈধ/অনুমতিপ্রাপ্ত মক্কার আজানের MP3 `app/src/main/res/raw/adhan_makkah.mp3` নামে রেখে আবার বিল্ড করুন। কোড বদলাতে হবে না। বিল্ড ছাড়াও চলবে: অ্যাপের সেটিংস থেকে ফাইলটি বেছে নিলেই হবে।

## রিমাইন্ডার
- আজানের আগে: ৫/১০/১৫/২০/৩০/৪৫/৬০ মিনিটের মধ্য থেকে **এক বা একাধিক** বাছাই করা যায় (যেমন ১৫ ও ১০ মিনিট আগে দুইবার)।
- আজানের পরে: ০ থেকে ৫ বার, প্রতি ৫/১০/১৫/২০/৩০ মিনিট পর পর।
- প্রতি ওয়াক্তে আজানের সময় নিজের মতো নির্ধারণ করা যায় (ওয়াক্ত → "আজানের সময় নির্ধারণ")।

## জেলা নির্বাচন
সেটিংস → জেলা থেকে **ম্যাপ** (বিন্দুতে ট্যাপ) অথবা **তালিকা** (সার্চসহ) দিয়ে ৬৪টি জেলার যেকোনোটি বাছা যায়।

## কীভাবে কাজ করে
- `PrayerCalculator`: সম্পূর্ণ অফলাইন জ্যোতির্বিজ্ঞান-ভিত্তিক গণনা (কারাচি ১৮°/১৮°, আসর হানাফি/শাফেয়ি)। ডিফল্ট: হবিগঞ্জ (২৪.৩৭৪৫°N, ৯১.৪১৫৬°E)।
- `AlarmScheduler`: `setAlarmClock` দিয়ে পরের ওয়াক্তের একটি এক্স্যাক্ট অ্যালার্ম; বাজার পর পরেরটি সেট হয়। ডোজ মোডেও কাজ করে, বাড়তি অনুমতি লাগে না।
- `AdhanService`: ফোরগ্রাউন্ড সার্ভিস, `USAGE_ALARM` অডিও, তাই স্ক্রিন অফ থাকলেও বাজে এবং AUX/ব্লুটুথ স্পিকারে যায়।
- `BootReceiver`: রিস্টার্ট, অ্যাপ আপডেট, সময়/টাইমজোন বদলালে অ্যালার্ম আবার সেট করে।

## প্রথমবার ব্যবহারে
- নোটিফিকেশন অনুমতি দিন।
- সেটিংস → "ব্যাটারি সীমা বন্ধ করুন" থেকে এই অ্যাপকে Unrestricted করুন (Xiaomi/Oppo/Realme/Vivo ফোনে অটো-স্টার্টও চালু করুন)।
- স্থানীয় মসজিদের জামাতের সময়ের সাথে মিলিয়ে প্রতি ওয়াক্তে মিনিট সমন্বয় করে নিন।
